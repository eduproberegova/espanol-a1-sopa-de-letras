# ESPAÑOL A1 · Sopa de Letras

Interactive Spanish A1 word search for vocabulary practice by theme.

Designed by [@eduproberegova](https://www.instagram.com/eduproberegova/).

## Features

- 15 vocabulary topics for Spanish A1 learners
- 3 levels: Facil, Medio, Dificil
- 6 / 9 / 12 words per puzzle
- Words are hidden until the learner finds them
- Ukrainian translations appear after each found word
- Helpful emoji markers for many vocabulary items
- Mobile friendly layout
- Print/PDF friendly with an `Imprimir` button
- Static site: no backend, no login, no build step

## How To Use

Open `index.html` in a browser, choose a topic and a level, then find the hidden words in the grid.

To save a printable version, use the `Imprimir` button and choose “Save as PDF” in the browser print dialog.

## Publish On GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, `README.md`, `favicon.svg`, `preview.svg`, and `preview.png`.
3. Open `Settings` -> `Pages`.
4. Choose `Deploy from a branch`.
5. Select the `main` branch and `/root` folder.
6. Save and wait for GitHub to publish the page.
